# Jeopardy! in Python

*Jeopardy!* in Python is exactly what it sounds like. The popular American game show, *Jeopardy!*, made for custom-playthroughs in Python! This project is targeted mostly towards classroom settings, but it can also be used in casual, work, and family environments for a shot at the game of *Jeopardy!* without all of the extra knowledge.

**V0.1.0.**

## Tech Stack

- Python
- Tkinter
- VisualTkinter.com

## Current Functionality

A blank, blue board.

## Planned Functionality

A fairly accurate copy of *Jeopardy!* adapted for a classroom setting with teams, scores, leaderboards, and interactivity.

**With...**

- Automatic score incrementation
- Customizable team counts
- Automatic winner selection and congratulations
- Question timers
- "Stealing" mode/logic
- Custom categories and questions

**And possibly...**

- An automatically generated answer sheet
- Up to 6 teams in play
- Team naming
- *Final Jeopardy!*
