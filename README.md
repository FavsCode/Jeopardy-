# Jeopardy! in Python

*Jeopardy!* in Python is exactly what it sounds like. The popular American game show, *Jeopardy!*, made for custom-playthroughs in Python! This project is targeted mostly towards classroom settings, but it can also be used in casual, work, and family environments for a shot at the game of *Jeopardy!* without all of the extra knowledge.

**V0.1.0.**

## Tech Stack

- Python
- Tkinter
- VisualTkinter.com

## Current Functionality

A blank, blue board.

## Planned Functionality

A fairly accurate copy of *Jeopardy!* adapted for a classroom setting with teams, scores, leaderboards, and interactivity.

**With...**

- Automatic score incrementation

- Automatic winner selection and congratulations
- Question timers
- "Stealing" mode/logic
- Custom categories and questions

**And possibly...**

- An automatically generated answer sheet
- Up to 6 teams in play
- Team naming
- *Final Jeopardy!*

## Usage

### Make sure you have Git installed to run the program

Install Git at: <https://git-scm.com/install/source>

#### 1. Clone/Download the repository

  ```bash
  git clone https://github.com/FavsCode/Jeopardy-in-Python.git
  cd Jeopardy-in-Python
  ```

#### 2. Create and activate a virtual environment (optional, but recommended)

##### *If on Mac or Linux*

  ```bash
  python -m venv venv
  source venv/bin/activate
  ```

##### *If on Windows*

  ```bash
  python -m venv venv
  source venv\Scripts\activate
  ```

### 3. Install the required dependencies

  ```bash
  pip install -r requirements.txt
  ```
