# *Jeopardy!* in Python

*Jeopardy!* is an American TV game show that quizzes contestants with general knowledge clues. The purpose of this adaptation is to recreate Jeopardy! for a classroom setting with teams, scores, leaderboards, and interactivity.  

**The point of this project is to create the fun and interacting game in Python!**
